# Driftae：R2 图片 → 独立站（你要做的几步）

## 设计说明：Trade Me relist 会变 URL

Trade Me **每次 relist 都会换** `/a/listing/数字` 这段链接。  
独立站用 **稳定 id**（如 `r2-06`，来自 R2 文件名 `06-xxx.jpg`），顾客始终打开：

`https://你的域名/product/r2-06`

会变的 Trade Me 链接单独放在 **`public/trademe-links.json`**，relist 后**只改这个文件**，不必改商品图、不必改 `products.json`。

---

## 一次性设置（约 5 分钟）

### 1. 创建 R2 只读 API Token

1. [Cloudflare Dashboard](https://dash.cloudflare.com) → **R2 object storage**
2. **Manage R2 API Tokens** → **Create API token**
3. **Object Read only**，bucket **`driftae`**
4. 保存 **Access Key ID** 和 **Secret Access Key**

### 2. 配置 `.env.local`

```bash
cp .env.example .env.local
```

填入两个 Key（不要提交 Git）。

### 3. 同步 R2 图片 → 商品目录

```bash
npm install
npm run sync:r2
```

生成 **`public/products.json`**（图、标题、稳定 `id`）。

### 4. 绑定 Trade Me listing（`public/trademe-links.json`）

同步后在终端或 `products.json` 里看 id，例如 `r2-06`：

```json
{
  "r2-06": {
    "listingId": 1234567890,
    "price": 89
  }
}
```

`listingId` = Trade Me 链接里 `/listing/` 后面的数字。  
也可以临时写完整 URL（relist 后建议改成新 `listingId`）：

```json
{
  "r2-06": {
    "trademeUrl": "https://www.trademe.co.nz/a/listing/1234567890",
    "price": 89
  }
}
```

### 5. 部署 Cloudflare Pages

Build: `npm run build`，Output: `dist`。

---

## Relist 之后（最常做）

1. 在 Trade Me 重新上架，复制**新** listing 链接  
2. 只编辑 **`public/trademe-links.json`**，更新对应 id 的 `listingId`  
3. `git push`（**不用** `npm run sync:r2`）

示例：新 listing 是 `9876543210`：

```json
{
  "r2-06": {
    "listingId": 9876543210,
    "price": 89
  }
}
```

卖掉了：

```json
{
  "r2-06": {
    "sold": true
  }
}
```

---

## 日常上新（R2 新图）

1. 上传 `07-商品名.jpg` 到 R2  
2. `npm run sync:r2` → 得到新 id（如 `r2-07`）  
3. 在 `trademe-links.json` 里加 `"r2-07": { "listingId": ... }`  
4. push  

---

## 文件分工

| 文件 | 会不会因 relist 改 | 内容 |
|------|-------------------|------|
| R2 图片 | 否 | 商品图 |
| `public/products.json` | 否（除非换图/sync） | 稳定 id、图 URL、标题 |
| `public/trademe-links.json` | **是** | listingId、价格、sold |
| `product-overrides.json` | 很少 | 标题/品牌等（sync 时合并） |

---

## 常见问题

| 问题 | 处理 |
|------|------|
| 独立站按钮链到旧 listing | 改 `trademe-links.json` 里的 `listingId` 后 push |
| `Missing R2 credentials` | 检查 `.env.local` |
| 网站没图 | R2 Public Development URL 是否开启 |
