# Driftae：R2 图片 → 独立站（你要做的几步）

## 一次性设置（约 5 分钟）

### 1. 创建 R2 只读 API Token

1. 打开 [Cloudflare Dashboard](https://dash.cloudflare.com) → **R2 object storage**
2. 右上角 **Manage R2 API Tokens** → **Create API token**
3. 权限选 **Object Read only**，限定 bucket **`driftae`**
4. 创建后保存 **Access Key ID** 和 **Secret Access Key**（Secret 只显示一次）

### 2. 在本项目根目录配置密钥

```bash
cp .env.example .env.local
```

编辑 `.env.local`，填入刚才的两个 Key（Account ID 和 Public URL 已写好，一般不用改）。

**不要把 `.env.local` 提交到 Git。**

### 3. 安装依赖并同步商品

```bash
npm install
npm run sync:r2
```

成功后会生成/更新 **`public/products.json`**（所有 R2 里的图片会自动变成商品条目）。

### 4. 补价格和 Trade Me 链接（可选）

打开 **`product-overrides.json`**，按商品 `id` 填写，例如同步后控制台会显示 `r2-06`：

```json
{
  "r2-06": {
    "price": 89,
    "trademeUrl": "https://www.trademe.co.nz/a/listing/1234567890"
  }
}
```

改完再执行一次 `npm run sync:r2`（会保留 overrides 里的价格/链接）。

### 5. 部署 Cloudflare Pages

- 把仓库连到 **Cloudflare Pages**，Build command: `npm run build`，Output: `dist`
- 每次 R2 上新图后：本地 `npm run sync:r2` → `git add public/products.json product-overrides.json` → push

---

## 日常流程（你老婆上新）

1. 图片上传到 R2 bucket **`driftae`**（建议文件名：`07-商品名.jpg`）
2. 你电脑上：`npm run sync:r2`
3. 需要的话改 `product-overrides.json` 里的价格
4. push → Pages 自动更新

---

## 常见问题

| 问题 | 处理 |
|------|------|
| `Missing R2 credentials` | 检查 `.env.local` 是否填好 |
| 网站没图 | 确认 R2 **Public Development URL** 已开启 |
| 中文文件名 | 脚本会自动 URL 编码，无需改 |
