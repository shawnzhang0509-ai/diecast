# 最快上架（不管 Trade Me）

只做三件事：**R2 传图 → 同步目录 → 部署**。

---

## 你要做的（一次性）

### 1. R2 只读 Token

Cloudflare → **R2** → **Manage R2 API Tokens** → **Object Read only** → bucket **`driftae`**。

### 2. 本机 `.env.local`

```bash
cp .env.example .env.local
```

填 `R2_ACCESS_KEY_ID` 和 `R2_SECRET_ACCESS_KEY`。

### 3. 同步 + 部署

```bash
npm install
npm run sync:r2
git add public/products.json
git commit -m "Sync products from R2"
git push
```

Cloudflare Pages 连这个仓库，`npm run build`，输出 `dist`。

**以后只上新图：** 上传到 R2 → 再跑一遍 `npm run sync:r2` → push `public/products.json`。

Trade Me、`trademe-links.json` 都可以先不管。

---

## 让 Cloud Agent 随时能读 bucket（推荐）

这样你不用每次发链接，在对话里说「同步一下 R2」就行。

1. Cursor → **Cloud Agents** → 本仓库的 **Environment / Secrets**
2. 添加（和 `.env.local` 相同，**只读 token 即可**）：

   - `R2_ACCOUNT_ID` = `7a9071e6af08d0a3d36c2678f1e6ea37`
   - `R2_BUCKET` = `driftae`
   - `R2_PUBLIC_BASE` = `https://pub-7deca3383c7c456a973f05394a5584be.r2.dev`
   - `R2_ACCESS_KEY_ID`
   - `R2_SECRET_ACCESS_KEY`

3. **新开一次 Cloud Agent**，我就能跑 `npm run sync:r2` 列出 bucket 里所有图。

Secrets 不要写进 Git。

---

## 可选：目录也放在 R2 上

Token 若有 **写** 权限，同步时：

```bash
R2_UPLOAD_CATALOG=1 npm run sync:r2
```

会把 `products.json` 上传到 bucket 根目录。  
站点可设 `VITE_PRODUCTS_URL=https://pub-…r2.dev/products.json`（需在 R2 开 **CORS** 才能从 Pages 域名 fetch）。

默认更简单：**`products.json` 跟着 Git push**，不用 CORS。
